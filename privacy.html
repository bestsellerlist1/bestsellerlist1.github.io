Política de Privacidad

Última actualización: 13 de mayo de 2026
Aplicación: Amazon Best Seller Bot

En Chaguarche (contacto: chaguarche.tours@gmail.com), nos tomamos en serio tu privacidad. Esta política explica qué datos recopila nuestra aplicación, cómo los usamos y qué derechos tienes.

1. Información que recopilamos

La aplicación interactúa exclusivamente con la API de Pinterest. Para que funcione correctamente, necesitamos acceder a:

  • Perfil público de Pinterest (ID de usuario, nombre de usuario).
  • Tableros de Pinterest (solo lectura para identificar el tablero destino).
  • Creación de Pines (escritura) – para publicar el contenido generado en tu cuenta.

No recopilamos ni almacenamos información personal adicional como contraseñas, direcciones IP, datos de navegación, ni información de tarjetas de crédito. Tampoco recopilamos datos de terceros.

2. Cómo utilizamos tus datos

  • Los datos obtenidos de la API de Pinterest se usan únicamente para ejecutar las funciones del bot: autenticarte, listar tus tableros y publicar Pines automáticos.
  • No compartimos, vendemos ni alquilamos tu información a nadie.
  • No utilizamos tus datos para perfiles de marketing o publicidad fuera de la propia funcionalidad de la app.

3. Almacenamiento y seguridad

Tu token de acceso se almacena de forma local en tu propio equipo (archivo .env) y nunca es enviado a nuestros servidores. Nosotros no tenemos acceso a tus credenciales. La aplicación se ejecuta en tu entorno local (Windows, macOS, etc.) y todas las comunicaciones con la API de Pinterest se realizan directamente desde tu máquina mediante conexiones cifradas TLS.

No mantenemos bases de datos externas con información de usuarios. Los registros de actividad (logs) pueden generarse localmente para depuración, pero tú controlas su eliminación.

4. Permisos de la API de Pinterest

Esta aplicación solicita los siguientes scopes durante el flujo de autorización OAuth:

  • boards:read – para obtener la lista de tus tableros y seleccionar el de destino.
  • pins:write – para crear nuevos Pines en tu nombre.
  • user_accounts:read – para verificar tu identidad y mostrar tu nombre de usuario.

No solicitamos permisos para gestionar anuncios, leer mensajes privados ni acceder a información de seguidores.

5. Tus derechos

Puedes revocar el acceso de esta aplicación en cualquier momento desde la sección "Apps conectadas" de la configuración de tu cuenta de Pinterest. Si deseas eliminar cualquier dato residual, puedes contactarnos y te orientaremos, aunque al ser una app local no almacenamos datos centralizados.

6. Menores de edad

Nuestros servicios no están dirigidos a menores de 13 años. No recopilamos intencionadamente información de niños.

7. Cambios en esta política

Si modificamos esta política, actualizaremos la fecha de "Última actualización". Te recomendamos revisarla periódicamente.

8. Contacto

Para cualquier pregunta sobre privacidad o para ejercer tus derechos, escríbenos a: chaguarche.tours@gmail.com.
